# Why LangChain?

Raw Ollama works for small scripts.

As applications grow, we need:

* Prompt management
* Reusable templates
* Structured outputs
* Retrieval pipelines
* Memory
* Agent workflows
* LangGraph integration

LangChain provides the architecture for these features.

# Key Concepts Learned

## 1. ChatOllama

LangChain wrapper around local Ollama models.

Example:

```python
from langchain_ollama import ChatOllama

llm = ChatOllama(
    model="gemma4:e2b",
    temperature=0.3
)
```

Purpose:

* Centralized model configuration
* Reusable across the application

---

## 2. PromptTemplate

Prompt templates allow dynamic variable injection.

Example:

```python
PromptTemplate.from_template(
"""
Question:
{question}

Answer:
{answer}
"""
)
```

Input:

```python
{
    "question": "What is RAG?",
    "answer": "Retrieval Augmented Generation"
}
```

Output:

```text
Question:
What is RAG?

Answer:
Retrieval Augmented Generation
```

---

## 3. Chains

A chain connects components together.

Example:

```python
question_chain = (
    question_prompt
    |
    llm
)
```

Meaning:

```text
Prompt
    ↓
LLM
    ↓
Response
```

This is the foundation of LangChain.

---

## 4. invoke()

Used to execute a chain.

Example:

```python
response = chain.invoke(
    {
        "topic": "Embeddings"
    }
)
```

LangChain automatically:

1. Fills prompt variables
2. Sends prompt to LLM
3. Returns result

---

## 5. AIMessage

LangChain does not return plain text.

It returns:

```python
AIMessage(...)
```

Therefore:

```python
response.content
```

is required to extract the actual text.

---

## 6. Structured Outputs

The evaluator returns JSON instead of free-form text.

Example:

```json
{
  "score": 8,
  "strengths": [
    "Good explanation"
  ],
  "weaknesses": [
    "Missing details"
  ],
  "improvement": "Provide examples"
}
```

Benefits:

* Easier parsing
* Easier storage
* Easier analytics
* Future memory integration

---

## 7. JSON Parsing

Convert model output into Python objects.

Example:

```python
import json

parsed = json.loads(response_text)
```

Result:

```python
{
    "score": 8
}
```

instead of a raw string.

# Important Bug Encountered

## PromptTemplate JSON Curly Brace Error

Problem:

```python
{
  "score": 0
}
```

inside PromptTemplate caused:

```text
KeyError:
Input to PromptTemplate is missing variables
```

Reason:

LangChain interprets:

```python
{score}
```

as a variable placeholder.

It expected a variable named:

```python
score
```

but none was provided.

---

## Solution

Escape JSON braces.

Wrong:

```python
{
  "score": 0
}
```

Correct:

```python
{{
  "score": 0
}}
```

Rule:

* Single braces `{}` → Variables
* Double braces `{{}}` → Literal text

# Interview Questions

## What is LangChain?

Framework for building LLM applications using reusable components such as prompts, chains, memory, retrievers, and agents.

---

## Why use LangChain instead of raw API calls?

* Cleaner architecture
* Reusable prompts
* Easier RAG integration
* Easier memory integration
* Easier LangGraph integration

---

## What is a PromptTemplate?

Reusable prompt containing variables that are filled dynamically at runtime.

---

## What is a Chain?

A pipeline connecting multiple components.

Example:

```text
Prompt
    ↓
LLM
```

---

## What is invoke()?

Method used to execute a chain and obtain a response.

---

## What is AIMessage?

LangChain wrapper object containing model responses.

---

## Why return JSON from an LLM?

To make outputs predictable, machine-readable, and easier to integrate into downstream systems.
