
# What is an LLM?

A Large Language Model predicts the next token
based on previous tokens.

Examples:

- Gemma
- Llama
- Qwen

# What is a System Prompt?

Instructions that define model behavior.

Example:

"You are a senior AI interviewer."

# What is a User Message?

Input from the user.

# What is an Assistant Message?

Response generated by the model.

# What is Temperature?

Controls randomness.

Low Temperature:
More deterministic.

High Temperature:
More creative.
