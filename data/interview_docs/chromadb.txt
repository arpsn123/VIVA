TOPIC: ChromaDB

DEFINITION

ChromaDB is an open-source vector database designed for AI applications.

It is widely used in RAG systems.

---

FEATURES

Stores embeddings

Performs similarity search

Supports metadata

Easy Python integration

Local deployment

CHROMADB IN VIVA

VIVA uses ChromaDB as its vector store.

Knowledge base documents are embedded and stored inside ChromaDB.

Retrievers query ChromaDB to obtain relevant context.
