TOPIC: YOLO (You Only Look Once)

OVERVIEW

YOLO stands for "You Only Look Once."

YOLO is a real-time object detection algorithm used in Computer Vision to identify objects and locate them within an image or video.

Unlike traditional object detection models that perform object localization and classification in separate stages, YOLO performs both tasks in a single forward pass through a neural network.

This makes YOLO one of the fastest object detection frameworks available.

Applications include:

* Autonomous Vehicles
* Security Surveillance
* Face Detection
* Traffic Monitoring
* Retail Analytics
* Drone Vision Systems
* Medical Imaging
* Industrial Inspection

---

WHAT IS OBJECT DETECTION?

Object Detection answers two questions:

1. What object is present?
2. Where is the object located?

Example:

Image contains:

* Dog
* Car
* Person

Output:

Dog:
Bounding Box Coordinates

Car:
Bounding Box Coordinates

Person:
Bounding Box Coordinates

Object Detection = Classification + Localization

---

OBJECT DETECTION VS IMAGE CLASSIFICATION

Image Classification:

Input:
Image

Output:
Cat

Only predicts what is present.

---

Object Detection:

Input:
Image

Output:

Cat → Location

Dog → Location

Person → Location

Predicts both class and location.

WHY YOLO WAS CREATED

Goal:

Perform object detection fast enough for real-time applications.

Main Idea:

Treat object detection as a single regression problem.

Instead of:

Region Proposal → Classification

YOLO directly predicts:

* Bounding Boxes
* Object Confidence
* Class Probabilities

In one neural network pass.

IMAGE GRID CONCEPT

YOLO divides the image into a grid.

Example:

7 × 7 Grid

Each grid cell is responsible for detecting objects whose centers fall inside that cell.

Example:

Image:

Dog in left corner

The grid cell containing the dog's center predicts the dog.

---

YOLO OUTPUT

Each grid cell predicts:

1. Bounding Box Coordinates

x

y

width

height

2. Confidence Score

Probability that an object exists.

3. Class Probabilities

Examples:

Dog

Cat

Car

Person

---

BOUNDING BOX

A bounding box is a rectangle surrounding an object.

Representation:

(x, y, w, h)

Where:

x = center x-coordinate

y = center y-coordinate

w = width

h = height

Example:

Person detected at:

(200, 150, 100, 300)

---

CONFIDENCE SCORE

Confidence Score measures:

1. Object existence probability
2. Localization quality

Range:

0 to 1

Example:

0.95

Means:

95% confidence that an object exists.

---

CLASS PROBABILITY

YOLO predicts probabilities for each class.

Example:

Dog = 0.90

Cat = 0.05

Horse = 0.03

Car = 0.02

Prediction:

Dog

Example:

Small Box

Medium Box

Large Box

---

INTERSECTION OVER UNION (IoU)

IoU measures overlap between:

Predicted Box

and

Ground Truth Box

Formula:

IoU = Overlap Area / Union Area

Range:

0 to 1

Interpretation:

1 = Perfect match

0 = No overlap

Higher IoU means better localization.

---

NON-MAXIMUM SUPPRESSION (NMS)

Problem:

Multiple boxes may detect the same object.

Example:

5 boxes around one dog.

Solution:

Non-Maximum Suppression

Process:

Keep highest confidence box.

Remove overlapping lower-confidence boxes.

Benefits:

Cleaner detections.

---

LOSS FUNCTION

YOLO optimizes multiple objectives simultaneously.

Components:

Localization Loss

Bounding box accuracy.

Classification Loss

Class prediction accuracy.

Confidence Loss

Objectness prediction accuracy.

Total Loss:

Combination of all losses.

COMMON INTERVIEW QUESTIONS

Q: What does YOLO stand for?

A: You Only Look Once.

Q: Why is YOLO faster than R-CNN?

A: YOLO performs object detection in a single neural network pass, while R-CNN uses multiple stages including region proposal and classification.

Q: What is a bounding box?

A: A rectangular box that identifies an object's location in an image.

Q: What is IoU?

A: Intersection over Union, a metric measuring overlap between predicted and actual bounding boxes.

Q: What is Non-Maximum Suppression?

A: A technique used to remove duplicate detections and keep the best bounding box.

Q: What are anchor boxes?

A: Predefined box templates used to detect objects of various sizes and shapes.

Q: What is the role of the backbone in YOLO?

A: Feature extraction from images.

Q: What is the role of the neck?

A: Combining multi-scale features before prediction.

Q: What is the role of the detection head?

A: Predicting bounding boxes, confidence scores, and object classes.

Q: Why is YOLO suitable for real-time applications?

A: Because it performs detection in a single forward pass with low latency.
